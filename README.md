# Сайт клининговой компании «Чисто»

Сайт для компании услуг с удобной админкой. Владелец сам меняет цены, услуги, отзывы, вопросы и контакты, не трогая код, и ведёт заявки с сайта: статусы, заметки, фильтры и поиск.

**Демо:** [ССЫЛКА_НА_RENDER]

## Возможности

**Сайт**
- Адаптивная главная: услуги с ценами, этапы работы, отзывы со звёздами, FAQ, форма заявки
- Кнопка «Заказать» у услуги сама подставляет её в форму
- Маска телефона и проверка полей на сервере
- Защита от спама: поле-ловушка и не больше одной заявки в минуту
- Заявка сохраняется в базу и сразу прилетает в Telegram

**Админка**
- Услуги: цена, порядок и видимость меняются прямо в списке
- Отзывы: публикация одной галочкой
- Заявки: цветные статусы, смена статуса из списка, массовые действия, поиск по имени и телефону, фильтр по дате и услуге
- Настройки сайта (заголовок, телефон, адрес, часы работы) в одной форме

## Стек

Python 3.12, Django 5.2, PostgreSQL / SQLite, WhiteNoise, Gunicorn. Вёрстка без фреймворков.

## Структура

```
company-site\
├── config\                     настройки проекта
├── main\
│   ├── models.py               услуги, отзывы, FAQ, заявки, настройки сайта

│   ├── views.py                главная и приём заявок
│   ├── forms.py                форма заявки с проверками

│   ├── static\main\            CSS и JS

```

## Запуск локально

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

Сайт: http://127.0.0.1:8000, админка: http://127.0.0.1:8000/admin.

## Деплой на Render

На бесплатном Render диск стирается при каждом перезапуске, поэтому данные хранятся во внешней базе PostgreSQL.

1. Создай бесплатную базу на [neon.tech](https://neon.tech) и скопируй строку подключения (`postgresql://...`).
2. Залей проект на GitHub.
3. На [render.com](https://render.com): **New → Blueprint** и выбери репозиторий.
4. Заполни переменные:
   - `DATABASE_URL`: строка из Neon
   - `DJANGO_SUPERUSER_USERNAME`, `DJANGO_SUPERUSER_PASSWORD`, `DJANGO_SUPERUSER_EMAIL`: логин и пароль от админки, создадутся при первой сборке
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: необязательно, для уведомлений о заявках

`SECRET_KEY` Render сгенерирует сам. При сборке `build.sh` применяет миграции и заполняет сайт демо-контентом, если база пустая.
